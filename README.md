# ☕ على القهوة — ألعاب السهرة التفاعلية (Ala El-Ahwa)

منصة ألعاب جماعية عربية تفاعلية مصممة للسهرات وتجمعات الأصدقاء بروح المقاهي الشعبية الدافئة (طراز ورق كرتون بيج، رسومات مرسومة يدوياً، بدون أي إيموجيز).

---

## 🎮 الألعاب المتاحة

1. **كرك (لعبة الخداع - بنمط kalak / Fibbage):**
   - سؤال حقيقي غريب به فراغ `____`.
   - كل فريق يكتب إجابة مزيفة مقنعة تخدع الفريق الآخر.
   - تظهر 6 إجابات مخلوطة (1 صحيحة + 2 كذبة الفريقين + 1 كذبة الحكم + 2 كذبة الذكاء الاصطناعي).
   - النتيجة: (+10 للصح، +5 لكل فريق يتخدع بكذبتك، -5 لكذبة الحكم أو الـ AI).

2. **سحلب (سلم التلميحات):**
   - صورة مموهة و5 تلميحات متدرجة بالصعوبة تكشف تدريجياً.
   - التخمين المبكر يمنح نقاطاً أعلى، والخطأ يجمد الفريق حتى التلميح القادم.

3. **لبن تمر هندي (ساعة الشطرنج والتخمين):**
   - كل فريق لديه شخصية سرية ويطرح أسئلة (نعم / لا).
   - ساعة شطرنج تنازلية لكل فريق، مع نظام "الفرصة الذهبية" عند خطأ الخصم وعقوبات تضليل.

---

## 🚀 طريقة التشغيل السريعة (Localhost)

### 1. تثبيت المتطلبات:
تأكد من وجود [Node.js](https://nodejs.org/) مثبت على جهازك.

```bash
npm install
```

### 2. تشغيل السيرفر:
```bash
npm start
```
أو:
```bash
node server.js
```

### 3. فتح اللعبة:
- **الحكم (الأدمن):** افتح المتصفح على: `http://localhost:3000`
- **اللاعبين من الموبايل:** امسحوا كود الـ QR الظاهر في غرفة الانتظار (أو ادخلوا عبر الرابط بالشبكة المحلية `http://<IP>:3000/room/<CODE>`).

## 📁 هيكلية المشروع

```text
├── assets/             # صور ورسومات اللعبة والشخصيات
├── questions/          # بنوك الأسئلة ومحرك عدم التكرار (220+ كرك، 70 سحلب، 80 تمر هندي)
├── app.js              # منطق الواجهة والتفاعل (Client SPA)
├── avatar.js           # محرك بناء الشخصيات الكرتونية المخصصة (SVG Rig)
├── index.html          # الصفحة الرئيسية
├── server.js           # خادم اللعبة اللحظي (Node.js + SSE)
├── styles.css          # نظام التصميم (Retro Coffee Paper Theme)
└── package.json        # تبعيات وإعدادات المشروع
```

## 🛠️ المميزات التقنية
- **مزامنة لحظية عبر Server-Sent Events (SSE)** بدون الحاجة لمكتبات معقدة.
- **خصوصية شاشة الحكم:** لا يتم إرسال الإجابات الصحيحة لهواتف اللاعبين إلا بعد مرحلة الكشف.
- **بنك أسئلة لا يتكرر أبداً:** نظام حفظ ومعالجة نصوص يمنع تكرار أي سؤال تم طرحه مسبقاً مع توليد تلقائي ذكي عند نفاد الأسئلة.
- **توليد أكواد QR حقيقية** قابلة للمسح مباشرة من كاميرا الهاتف.
